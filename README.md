# Al Habib Bakery

A React Native application for bakery inventory and sales management, supporting both mobile and desktop platforms.

## Features

- User Authentication (Login, Register, Password Reset)
- Product Management (CRUD operations)
- Sales Tracking
- Product Categories Management
- Dashboard with Statistics
- Local Data Storage

## Installation

```bash
npm install
```

## Running the App

- **Web**: `npm run web`
- **iOS**: `npm run ios`
- **Android**: `npm run android`
- **Start**: `npm start`

## Project Structure

- `/src/screens` - Screen components
- `/src/components` - Reusable components
- `/src/services` - Data storage and business logic
- `/src/navigation` - Navigation configuration
- `/src/utils` - Utility functions
